Detailed Description

Main orchestrator for the Fiber Packing System (FPS).

Coordinates the multi-phase generation process:

  1. Constructive placement (CSAW), 2. Dynamic optimization,
  2. Topological validation, 4. Porosity generation, and 5. Multi-format exports (GMSH, Voxel, CSV, JSON).
