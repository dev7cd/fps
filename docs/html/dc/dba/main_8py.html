Detailed Description

Main orchestrator for the Fiber Packing System (FPS).

Coordinates the multi-phase generation process:

  1. Constructive placement (CSAW), 2. Dynamic optimization,
  2. Topological validation, 4. Porosity generation, and 5. Multi-format exports (GMSH, Voxel, CSV, JSON).

Final audit, porosity, statistics and exports of the generated fibers.

The blocking audit (F03) runs on the fibers transmitted to the exports, before any other output: on failed or undetermined it writes <prefix>_validity.json and exits with code 1, leaving earlier exports of the same prefix untouched.

Parameters
configThe configuration object.
fibersFinal fibers (roots), not modified after the audit.
t_startStart time of the run.
timingsdict of phase durations (seconds) measured so far, completed here.
argsParsed CLI namespace, stored in the parametric record.
voidsPores to export as they are (regeneration from a record); None generates them when porosity is enabled.
Returns
None

Saves the RVE geometry and certified analysis results to a JSON file.

This "O1" record contains metadata, simulation parameters, computed microstructural statistics, and the raw control points for every fiber.

Parameters

stats_dictDictionary containing AD-PCA and spatial statistics.

timingsWall-clock duration of each phase in seconds, stored under "timings_s".
