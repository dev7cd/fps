Detailed Description

Command Line Interface (CLI) for the Fiber Packing System.

Parses user arguments and maps them to the FiberPackingConfig object to control RVE generation, optimization, and export.

◆ parse_args()

def cli.parse_args (   argv = None)

Parses command line arguments and initializes the configuration.

Organizes arguments into logical groups (Domain, Geometry, Trajectory, Optimization, Porosity, and System) and performs necessary unit conversions (e.g., degrees to radians for curvature). When no seed is given, one is drawn from the operating system and stored in args.seed, so that every run is reproducible from its record.

Parameters
argvArgument list (None: sys.argv[1:]).
Returns
A tuple containing (config, args) where config is a FiberPackingConfig instance and args is the raw argparse Namespace.
