Detailed Description

Class for validating the topological integrity of fiber microstructures.

Provides methods to check for intersections and analyze the distribution of distances between fibers.

Calculates the exact minimum clearance (empty space) between all fiber pairs.

Uses exact segment-to-segment distance with Minimum Image Convention (MIC). A result > 0 indicates no intersections.
