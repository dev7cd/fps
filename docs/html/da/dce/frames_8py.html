Detailed Description

Local frame computation along 3D curves.

Implements Parallel Transport (Bishop Frame) to minimize torsion and provides utilities for tangent vector calculation.

Tuple[np.ndarray, np.ndarray, np.ndarray] geometry.frames.compute_bishop_frame ( np.ndarray  points)

Computes the Bishop frame (Tangent, Normal, Binormal) along a curve.

Uses the Parallel Transport method to propagate the normal vector along the curve, which avoids the "twisting" artifacts of Frenet-Serret frames at points of zero curvature.

Parameters
pointsArray of shape (N, 3) representing the curve points.
Returns
A tuple (T, N, B) where each is an array of shape (N, 3).
