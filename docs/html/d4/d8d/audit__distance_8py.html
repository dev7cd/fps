Detailed Description

Distance kernel of the final geometric audit (F03), independent of the collision detector used during generation.

The generation detector (collision/detector_math.py) compares scale-dependent quantities with an absolute threshold and can overestimate the distance between short or nearly parallel segments. This module does not call it. Its decisions are invariant under a common change of scale:

  • Minimum of |P(s) - Q(t)|, P(s) = A + s d1, Q(t) = C + t d2, (s, t) in [0, 1]^2. The minimum of this convex function lies either on an edge of the square (one of the four endpoint-to-segment distances) or at the interior stationary point. All five candidates are kept; the interior one is never replaced by an endpoint fallback.
  • Interior candidate, when the segments are not nearly parallel (|n|^2 > NEAR_PARALLEL * a * e, n = d1 x d2 formed directly, a = |d1|^2, e = |d2|^2, no a*e - b*b): s = ((C - A) x d2) . n / |n|^2, t = ((C - A) x d1) . n / |n|^2 and, when both lie in [0, 1], the line-to-line distance |(C - A) . n| / |n|. This distance never exceeds the true segment distance, so a misclassified interior point can only make the audit more conservative.
  • Nearly parallel segments (0 < |n|^2 <= NEAR_PARALLEL * a * e): the direction of n carries a relative error of order eps / sin(theta), which the line distance multiplies by |C - A|. The interior minimum is then found from the convex function g(s) = dist(A + s d1, [C, E]) (distance of an affine point to a convex set) by golden-section search down to |delta s| <= S_TOL: the value returned is attained by a point of the first segment, so it can exceed the minimum by at most |d1| * S_TOL, plus the point-to-segment rounding.
  • n = 0 exactly (parallel or degenerate segments): the edge candidates give the exact minimum. Zero-length segments are treated as points.
  • Interior point-to-segment distances use |w x d| / |d| (no cancellation in |w|^2 - proj^2).

Periodic images: for two polylines with coordinate intervals [a_min, a_max] and [b_min, b_max] on an axis of period L, the shift k minimising |p - q - kL| for any pair of points lies in [floor((a_min - b_max) / L), ceil((a_max - b_min) / L)]; one extra period is scanned on each side against rounding. The axes are independent, so this box of shifts contains the minimum over all images. A fiber is compared with its own non-zero images only.
