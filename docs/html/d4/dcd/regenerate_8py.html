Detailed Description

Regenerates every export of an RVE from its parametric record, without re-running placement.

The record <prefix>_parametric.json written by main.py stores the complete CLI argument set, the control points and radius of every fiber, and the pores. This tool rebuilds the configuration and the geometry from it, checks that the rebuilt fibers are bit-identical to the audited ones (SHA-256 of microstructure_data), re-runs the blocking geometric audit, and writes the statistics, CSV, voxel field, PGM slices, CAD/mesh and optional Nastran/Abaqus files.

Only export options may differ from the original run, for example a finer voxel grid: 

python regenerate.py RVE_parametric.json --res_fft 512 --no_mesh --output RVE_512

Arguments that shape the geometry (–vf, –radius, –seed, ...) are fixed by the record.
